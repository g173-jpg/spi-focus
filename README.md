# SPI FOCUS

非公式のSPI練習用模試。全459問、WEBテスティング形式・テストセンター形式、3段階の難易度自動調整、採点と解説を収録しています。

テストセンター形式の実戦模試には英語を含みます。仕事算20問は両形式に収録しています。

## GitHub Pagesで公開

1. このフォルダー内のindex.htmlとREADME.mdをリポジトリの最上位にアップロードします。
2. Settings → Pagesを開きます。
3. SourceでDeploy from a branchを選びます。
4. Branchをmain、フォルダーを/(root)に設定し、Saveを押します。
5. Pages画面に表示されるURLを開きます。

ZIPそのものをリポジトリにアップロードせず、展開した中のファイルをアップロードしてください。

## 利用について

index.htmlを直接ブラウザーで開いても動作します。出題履歴は利用者のブラウザー内に保存します。
問題、問題数、1問の制限時間、難易度調整は練習用の独自設定です。本番の問題・採点方式を再現するものではありません。
参考資料はサイト内に掲載しています。
